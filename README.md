# 🎓 학술제 HTML 슬라이드덱 제작 프로젝트

이 저장소는 **작성하신 보고서를 고품질 학술 발표용 HTML 슬라이드덱으로 변환**하고, **체계적인 레퍼런스(출처) 관리** 및 **AI와의 원활한 협업 소통**을 위해 구성된 작업 공간입니다.

---

## 📂 폴더 구조 안내

```text
학술제1/
├── 📁 00_소통_가이드/               # AI와의 협업 소통 창구 및 기획 문서
│   ├── README.md                   # 협업 가이드 & 작업 룰
│   ├── 체크리스트.md                # 진행 상황 추적 (To-Do / 완료 내역)
│   ├── 슬라이드_구성안.md            # 장표별 목차, 메시지, 대본 초안
│   └── 피드백_요청노트.md           # 수정/보완 요청사항 기록
│
├── 📁 01_보고서_원고/               # 사용자가 작성한 보고서 원문 보관
│   ├── README.md                   # 보고서 등록 가이드
│   └── (여기에 보고서 파일(.docx, .pdf, .txt, .md 등)을 넣어주세요)
│
├── 📁 02_참고자료_레퍼런스/          # 논문, 기사, 차트 등 인용 출처 관리
│   ├── 참고문헌_목록.md             # [Ref-01] 인용 번호와 서지 정보 마스터 시트
│   ├── 📁 논문_기사_텍스트/         # 참고 논문 PDF, 학술지, 기사 발췌문
│   ├── 📁 이미지_도표_차트/         # 슬라이드에 삽입할 시각 자료 및 그래프
│   └── 📁 데이터_통계_자료/         # 설문 결과, 통계 엑셀, CSV 원본
│
├── 📁 03_HTML_슬라이드/             # 실제 구동되는 HTML 슬라이드덱 소스
│   ├── index.html                  # 슬라이드 실행 메인 파일 (더블클릭 시 브라우저 실행)
│   ├── 📁 css/                     # 학술 발표용 모던 스타일시트
│   ├── 📁 js/                      # 키보드 컨트롤(←, →, F), 레퍼런스 토글 등
│   └── 📁 images/                  # 슬라이드에 실제 사용되는 최적화 이미지
│
└── 📁 04_최종_출력물/               # 발표 준비 완료본 및 PDF 배포본
    └── README.md                   # 최종 발표 및 인쇄/PDF 변환 가이드
```

---

## 🚀 빠른 시작 가이드 (3 Step)

### Step 1. 보고서 원문 넣기
- 작성하신 보고서 파일(워드, 한글 텍스트 복사본, 마크다운, PDF 등)을 **`01_보고서_원고/`** 폴더에 넣어주세요.

### Step 2. AI에게 분석 요청하기
- 채팅창에 다음과 같이 편하게 말씀해주세요:
  > *"01_보고서_원고에 보고서를 넣었어. 전체 내용을 분석해서 슬라이드 구성안을 잡아줘."*

### Step 3. 레퍼런스 연결 및 슬라이드 제작
- 참고한 논문/출처는 **`02_참고자료_레퍼런스/참고문헌_목록.md`**에 기록하고, 슬라이드 각 장표 하단에 각주(Footnote)로 자동 연결됩니다.
- **`03_HTML_슬라이드/index.html`**을 크롬, 엣지 등 브라우저로 열면 바로 인터랙티브 발표 자료를 확인할 수 있습니다.
